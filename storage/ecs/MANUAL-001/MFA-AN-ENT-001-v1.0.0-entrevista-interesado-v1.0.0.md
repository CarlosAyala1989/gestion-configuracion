# Entrevista del interesado v1.0.0

Proyecto: MANUAL-001
Work item: WI-0001

El interesado solicita autenticacion multifactor para disminuir accesos no autorizados.
El flujo esperado es iniciar sesion con correo y contrasena, validar un segundo factor y registrar auditoria.

Criterios iniciales:
- El usuario activo debe configurar un segundo factor.
- El inicio de sesion debe registrar exito o fallo.
- QA debe validar el flujo funcional y de regresion.
